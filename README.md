# شحنات سيارتي – EV Charge Tracker

تطبيق لتسجيل ومتابعة شحنات السيارة الكهربائية. الواجهة صفحة ويب واحدة (`web/index.html`)
تعمل كرابط ويب، ويغلّفها تطبيق أندرويد (WebView) لتصبح APK.

## الميزات
- السيارة وسعة البطارية، وتسجيل الشحنة (قبل/بعد %) مع حساب kWh والقيمة، وتعديل أو حذف أي شحنة.
- عداد المسافة: قراءة بداية الشهر ونهايته → الكيلومترات، kWh/100كم، تكلفة الكيلومتر.
- تقويم شهري يعلّم أيام الشحن، مع أطول فترة بين شحنتين والمدة منذ آخر شحنة.
- مقارنة شهرين (جدول بنسب التغيّر) واتجاه شهري لكل مقياس.
- تصدير CSV (الشحنات أو الملخص الشهري)، ونسخة احتياطية JSON واستعادتها.
- ألوان ومظهر (فاتح/داكن) قابلة للتخصيص. يعمل بدون إنترنت.

## بناء الـ APK
- **بدون Android Studio:** ارفع المجلد إلى مستودع GitHub ← تبويب Actions ← Build APK ← نزّل `EVChargeTracker-apk`.
- **بـ Android Studio:** افتح المجلد وشغّل `sync-web.sh` ثم Run.

بعد أي تعديل على `web/index.html` شغّل `sh sync-web.sh` قبل البناء.
